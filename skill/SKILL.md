# SKI INNO WHY AI 릴스

요청된 단계부터 시작한다. 전편 제작 요청은 상영 가능한 MP4까지 진행한다. 회차의 기획안과 지급 음성을 기준으로 삼고, 수기 수정 사항은 해당 컷의 새 기준으로 기록한다. 시리즈명, 코너 표기, 워터마크와 장식 문구는 사용자나 회차 기획안에서 화면에 표시하도록 지정한 경우에만 넣는다. 파일명, 표지 제목, 참고 영상에만 있는 문구는 화면에 옮기지 않는다. 기존 편집본을 재사용할 때도 첫 컷을 포함해 같은 기준으로 확인한다.

1. **입력과 씬을 읽는다.** [공통 기획안 분석](references/brief.md)을 적용해 실제 슬라이드 화면과 원고를 대조한다. PPT 페이지마다 가안, 필수 카피, 숫자와 단위, 강조 시점, 마지막 로고와 CTA를 확인한다. 지급된 타입캐스트 음성은 디코딩하고 들어본다. 누락 시 화면 설계와 키프레임까지 진행하고, 실제 음성이 필요한 배치 단계에서 원본을 요청한다.
2. **화면 컷과 발화를 따로 설계한다.** 씬별로 보여 줄 사실, 대사 또는 호흡 ID, 발화의 어느 단어에서 무엇이 일어나는지, 예상 초수, 연결 방식, 시작과 끝의 화면 상태를 쓴다. 한 슬라이드를 여러 컷으로 나누거나 한 발화를 두 컷에 걸칠 수 있다. 독립 컷과 앞 컷의 채택본이 필요한 컷을 표시한다.
3. **참조를 골라 내부 이미지 모델에 전달한다.** [레퍼런스와 키프레임](references/keyframes.md)을 따른다. 기획자 가안, 신비한 건축사전 톤 캡처, 연속성용 채택본에 역할을 부여하고 매번 실제 파일을 첨부한다. 씬당 보통 시작과 끝 2장, 변신이나 이동에 중간 상태가 필요하면 3장으로 잡는다. 파일 수와 역할은 해당 생성에 맞게 정한다.
4. **씬 영상을 만든다.** [영상과 효과음](references/video-sound.md)을 따른다. 기본은 Higgsfield의 Seedance 2.0 Mini, 720p, 세로 9:16이다. 목표 초수는 씬 분석에서 가져온다. 음악을 제외하고 화면의 원인이 들리는 효과음만 사용한다.
5. **지급 음성을 편집하고 강조 정보를 합성한다.** [음성 편집과 모션 그래픽](references/edit.md)을 따른다. 내레이션 원본을 문장이나 호흡별로 배치하고, 기획안에 맞춰 자막과 포인트 그래픽을 합성한다. 씬 효과음 전체를 원본 대비 12 dB 낮추고, 뉴스룸 안내 발화에 맞춰 승인된 ASK Inno 엔딩 영상을 그대로 재생한다. 박스 안 텍스트는 행별 가로 중앙, 전체 글자 묶음은 세로 중앙에 맞춘다.
6. **결과와 다음 수정 지점을 남긴다.** 기본 출력은 H.264 MP4, 720×1280, 24fps, AAC다. 편집 가능한 자막, 무손실 분할 음성, 실제 타임라인과 원장도 보관한다. 파일을 다시 열어 영상과 음성, 글자, 엔딩을 확인하고 요청된 결과를 전달한다.

## 새 환경의 실행 도구

이 패키지의 Windows x64 실행기 `reels.cmd`를 사용한다. 스킬 위치를 기준으로 실행 파일을 찾고, 작업물은 사용자의 회차 폴더에 쓴다. [실행 방법과 타임라인 규격](references/local-tools.md)에서 기획안 열기, 음성 구간 초안, 참조 검색, 포인트 모션과 최종 렌더 방법을 읽는다. 회차 제작의 입력은 기획안과 지급 음성이다. 이미지 생성과 Higgsfield 도구는 현재 Codex 계정에서 찾고, 로그인한 사용자의 자격으로만 호출한다.

## 원장과 재개

회차별 원장은 기존 프로젝트 작업원장 방식을 이어 쓴다. 에이전트가 조회할 수 있는 JSON에 회차 입력 → 발화 및 씬 → 생성 시도 → 채택 파일 → 최종 타임라인과 출력 위치를 연결한다. 프롬프트 원문, 실제 첨부 파일 경로 또는 자산 ID와 순서, 모델 설정, 작업 ID, 채택 사유, 피드백 전후 파일을 남긴다. 사용자에게 보여줄 진행 기록에는 바뀐 결정과 현재 결과를 짧게 쓴다.

연결된 씬의 앞 프레임이 바뀌면 이를 참조한 다음 컷만 재검토한다. 발화 시간 수정은 해당 구간의 자막, 효과음, 그래픽, 뒷구간 시간에 전파한다. 이어서 작업할 때는 원장의 마지막 채택본과 미완료 작업 ID를 복원한다. 기준본이나 사용자 수기 편집본은 새 버전과 구분해 보존한다.

## 설치된 스킬 업데이트

사용자가 SKI 릴스 스킬의 업데이트를 요청하면 [공식 배포 저장소](https://github.com/hmhmkmr/ski-ai-reels-production)의 README에서 현재 Windows x64 업데이트 절차를 읽고 실행한다. 기존 설치 위치를 재사용하고 새 버전과 백업 위치를 알려준다. 이미 최신이면 확인 결과를 반환한다.
