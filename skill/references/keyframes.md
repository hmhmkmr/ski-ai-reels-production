# 레퍼런스 선택과 키프레임

SKI 기본 톤 라이브러리는 [신비한 건축사전 장면 목록](../assets/tone/catalog.json)이다. 새 캡처를 추가할 때는 영상 출처와 타임코드, 이미지 파일, 간단한 용도와 넓은 태그를 남긴다. 소재, 행동, 상태, 재질, 빛, 구도는 독립적으로 조합한다. 예를 들어 불이 난 교회 장면은 ‘불타는 모습’, ‘불붙은 건물’, ‘교회’로 찾을 수 있게 한다.

- 패키지 실행기의 `refs [태그 …] --limit 6`으로 후보 파일과 출처를 조회한다. 모든 태그가 맞는 장면을 우선하고, 없으면 일부 일치 순으로 찾는다. 남는 후보가 없으면 목록에 있는 빛이나 구도 태그 하나로 풀거나 태그 없이 여러 영상의 장면을 훑는다. 레퍼런스는 색감과 촬영 방식만 맞아도 쓸 수 있다.
- 생성 직전 후보를 실제로 열어 보고 이번 프레임에 필요한 파일만 고른다. 가안은 사건과 위치, 채널 캡처는 톤과 시점, 직전 채택본은 피사체와 방향을 맡긴다. 참조가 겹치면 덜어낸다. 2~3개는 흔한 출발점이다. 모델의 첨부 한도는 현재 도구 명세를 확인한다.
- 내부 이미지 모델의 파일 입력을 사용하고, 프롬프트에서 ‘첨부 1의 단면 구조, 첨부 2의 푸른 수중광’처럼 참조 순서와 차용 요소를 명시한다. 후보 경로를 프롬프트에 적은 것만으로 전달 완료 처리하지 않는다. 선택 파일, 제출 순서, 실제 인자에 사용한 경로 또는 이미지 식별자, 반환 결과와 채택 여부를 연결한다.
- 세로 화면에서 움직임의 시작과 끝이 읽히는지 비교한다. 연결할 컷은 시점, 빛, 재질과 진행 방향을 이어받고, 독립 컷은 가장 이해하기 쉬운 구도로 전환한다. 화면 안의 자막, 이름표, 숫자, 브랜드 로고는 후편집 자리를 비워 둔다. 동일 채택 파일을 두 씬에 사용하는 경우 양쪽에서 같은 파일을 가리킨다.
- 재질이나 형상이 핵심인 변신은 전후 조건을 따로 쓴다. 어스온 편에서는 변신 전 자연 털의 낙타, 변신 후 털결이 사라지고 금속 반사와 단단한 면이 나타나는 금 동상을 각각 판정했다. 넓은 화면에서만 수영장 형태가 읽혔을 때는 채택한 원경을 근경 재생성에 첨부했다. 이 피사체와 컷 수는 어스온 편의 사례다.
