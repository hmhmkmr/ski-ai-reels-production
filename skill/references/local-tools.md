# 로컬 도구와 편집 타임라인

아래 명령의 `reels`는 Windows 설치 폴더의 `reels.cmd`를 뜻한다. 다른 디렉터리에서 호출할 때는 실행기의 전체 경로를 쓴다. 새 파일은 회차 작업 폴더에 만들고 스킬 설치 폴더는 참조용으로 유지한다.

| 명령 | 입력과 결과 |
|---|---|
| `reels doctor` | 현재 CPU와 OS용 실행기, 자산 해시, FFmpeg, 캡처 수를 확인한다. 클라우드 로그인 상태는 해당 Codex 세션에서 확인한다. |
| `reels brief board.pptx new-board` | 슬라이드 순서대로 원문과 이미지, 노트, 외부 출처, 위치를 추출한다. 결과의 index.html과 storyboard.json을 읽는다. |
| `reels voice voice.mp3 new-voice ko` | CPU에서 동봉된 다국어 Whisper를 실행한다. 초 단위 구간과 쉼은 speech.json, 실제 구간 청취는 listen.html에 있다. |
| `reels refs 단면 자연광 --limit 4` | 전체 일치, 일부 일치, 영상별 탐색 순서로 PNG 절대 경로와 타임코드를 돌려준다. 선택 파일을 이미지 생성 도구에 별도로 첨부한다. |
| `reels init new-episode` | 입력 폴더와 편집 가능한 timeline.json, 작업원장 틀을 만든다. 예시 초수와 문구를 회차 원고로 교체한다. |
| `reels render timeline.json new-output` | 완료된 씬 MP4와 지급 음성, 효과음에서 최종 reel.mp4, SRT, 분할 WAV, 음성과 효과음 트랙, 재편집용 타임라인을 출력한다. |
| `reels smoke sample-new` | 로컬에서 두 컷, 한글 자막, 라벨, 지시선, 엔딩 로고와 테스트음을 실제 MP4로 렌더한다. 유료 모델 호출은 발생하지 않는다. |
| `reels outro new-overlay.mkv` | 동봉한 투명 엔딩을 다른 편집 도구에서 사용할 수 있도록 복사한다. |
| `reels media -i source.mp4 …` | 동봉 FFmpeg에 인자를 그대로 전달한다. 프레임 추출, WAV 추출, 미디어 점검에 사용한다. |

## timeline.json

`init`으로 만든 실제 JSON을 출발점으로 쓴다. 파일 경로는 타임라인 파일 위치 기준이다. 시간 단위는 초, 화면 좌표 단위는 픽셀이다. 출력 기본은 720×1280, 24fps다. 생성 원본과 사용 구간을 결정한 다음 아래 목록을 작성한다.

- `scenes`는 순서대로 이어지는 화면이다. 각 항목의 `file`, `from`, `to`는 원본 영상과 사용할 구간, `duration`은 편집본 길이다. 원본에서 시작과 끝이 보이는지 확인한다. 사용한 원본 구간 전체를 목표 시간으로 리타이밍한다.
- `voices`의 항목에 지급 음성의 `file`, 원본 `from`과 `to`, 편집본 시작 `at`을 지정한다. 같은 파일을 여러 구간으로 잘라 배치할 수 있다. 내레이션은 원래 속도로 재생한다.
- `sfx`에도 파일, 원본 구간, 편집 시작을 지정한다. 깨끗한 씬 영상의 오디오나 단독 효과음을 쓸 수 있다. `gainDb`는 효과음 레벨, 선택 항목 `duration`은 영상 리타이밍에 동기화할 길이다. 소리가 필요 없는 컷은 비워 둔다. 편집기는 전체 효과음에 고정 −12 dB를 한 번 적용한다. 일반적인 씬은 `gainDb`를 생략하거나 0으로 둔다. 직접 지정한 값은 개별 소스의 추가 보정이다. 출력된 `effects.wav`에는 전체 감쇠가 이미 적용되어 있다. 미지정 씬 오디오는 최종본에 섞이지 않는다.
- `captions`의 `start`, `end`, `text`로 자막과 SRT를 함께 생성한다. 강제 줄바꿈은 텍스트에 줄바꿈 문자를 쓰거나 `lines` 배열을 사용한다.
- `graphics`는 `label`, `leader`, `x`, `logo`, `image`를 지원한다. `x`, `y`는 박스의 가운데 좌표다. `width`, `height`, `start`, `end`, `enter`, `exit`, `rise`로 크기와 등장 시간을 조절한다. `toX`, `toY`는 끝 위치다. 지시선은 가로 방향으로 드러나며 `points`로 경로를 지정한다. 지시선과 라벨은 별도 이벤트로 발화 순서에 맞춰 등장시킨다.
- 라벨의 `lines`는 문자열이나 `{"text":"회수 가능 원유 자원량 추정치","size":22,"color":"#FFFFFF","weight":7}` 같은 행의 목록이다. `fill`, `radius`, `padding`, `gap`을 조절한다. 글자 외곽선까지 측정해 각 줄 가로 중앙, 전체 줄 묶음 세로 중앙으로 놓고 박스와 함께 움직인다. `logo`는 기본 ASK Inno 투명 파일을 쓰며 다른 회차의 지급 로고는 `file`로 지정한다.

- `endingAt`은 뉴스룸 호출 발화에 맞춰 반투명 딤과 ASK Inno 모션을 시작할 초수다. 모션과 두 줄 문구는 동봉한 투명 영상에서 읽는다. 이 지점부터 별도 말자막과 그래픽을 끝내고, 회차의 배경 영상과 내레이션, 효과음은 계속 재생한다. 마지막 씬은 이 시점부터 약 2.93초 동안 움직일 영상까지 잡는다. 부족한 구간만 마지막 프레임으로 연장한다.
- 시작값을 생략하면 구형 타임라인의 마지막 ASK Inno 로고 시각을 사용한다. 해당 표시도 없으면 계획한 씬이 끝나는 시점부터 적용한다. v1.2.0 타임라인에 남은 `endingFile`은 자동으로 건너뛰어 예전 회차 배경이 다시 들어오는 일을 막는다. 엔딩 파일은 업데이트에 들어 있다.

## 새 컴퓨터에서 생성 단계 연결

기획안과 지급 음성은 회차마다 입력한다. 레퍼런스 파일과 서체는 설치된 스킬에서 읽는다. 내부 이미지 생성 도구와 계정 접근 권한을 실제 세션에서 확인하고, Higgsfield 모델 조회로 Seedance 2.0 Mini의 현재 지원 옵션을 읽는다. 레퍼런스와 키프레임은 각 서비스의 실제 미디어 입력으로 전달하고 원장에 순서와 자산 ID를 남긴다. 도구 부재와 모델 미지원은 해당 단계의 상태로 기록한다. 패키지의 독립 편집기는 이미 생성한 클립으로도 작동한다.
