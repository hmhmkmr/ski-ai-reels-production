# 씬 영상과 효과음

영상 생성 직전 현재 Higgsfield MCP의 모델 목록과 Seedance 2.0 Mini의 스키마를 확인한다. 시작과 끝, 지원 시 중간 프레임이나 참조 미디어를 해당 입력 형태로 전달한다. 로컬 파일은 도구가 지원하는 미디어 전달 경로로 준비하고, 반환된 자산 식별자를 씬에 연결한다. 지원하지 않는 프레임 역할을 제출했다고 기록하지 않는다. 같은 효과를 위해 컷을 분할했으면 타임라인에 표시한다.

**프롬프트**에는 시작 상태, 시간 순서대로 일어날 한두 동작, 카메라와 피사체의 방향, 끝 상태, 소리 날 위치를 적는다. 기본은 720p, 9:16. 생성 직전 지원 초수와 해상도를 확인하고 씬 예정 길이에 맞춘다. 모델 최소 길이가 더 길면 합법적인 길이로 생성하고 편집에서 필요한 구간을 고른다. 눈에 보일 동작의 첫 상태와 끝 상태를 보존한다. 속도 조절이 필요하면 화면과 효과음의 타이밍을 같이 맞추고 음높이를 보존한다.

**소리**는 장면에 보이는 사건에서 시작한다. 예를 들어 ‘파도가 렌즈에 닿을 때 물이 한 번 부딪힌다. No music, score, melodic pad, vocals or dialogue.’처럼 쓴다. 필요한 경우 모델의 오디오 생성 옵션을 켠다. 음악이나 발화는 생성하지 않는다. 특정 소리가 필요 없는 컷은 조용하게 둔다. 바다라는 이유로 전편에 파도 루프를 깔거나 씬마다 배경음악을 붙이지 않는다.

**채택**은 영상 파일을 내려받아 실제로 디코딩하고, 영상 속 소리를 단독으로 들은 뒤 결정한다. 오디오 스트림 유무나 음량만으로는 음악 혼입을 판별할 수 없다. 음악이나 추가 음성이 섞인 경우 좋은 그림은 유지하고 해당 오디오를 제거한 뒤 동기화된 단독 효과음으로 교체한다. 적합한 효과음이 필요하면 해당 효과 또는 해당 컷만 다시 생성한다. 내레이션은 편집 단계의 별도 트랙에 둔다.

**재개**를 위해 작업 제출 직후 씬 ID, 참조 자산, 프롬프트, 실제 옵션과 작업 ID를 원장에 남긴다. 타임아웃은 기존 ID로 상태를 다시 읽고, 최종 오류나 교정 사유가 확인될 때 해당 씬만 재시도한다. 서로 독립된 씬은 동시 진행할 수 있다. 생성 원본 길이, 사용 구간, 편집본 시작과 끝을 각각 기록한다.
